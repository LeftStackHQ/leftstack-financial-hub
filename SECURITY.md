# Security policy

Financial Hub holds campaign finance records, so security reports matter. Thank you for taking the time.

## Reporting a vulnerability

Please **don't open a public issue** for a security problem.

Report it privately: open the **Security** tab of this repository and choose **Report a vulnerability**. Describe what you found, how to reproduce it, and which version you tested. If you can, leave out real donor information.

You'll get a reply as soon as someone can look at it, and we'll tell you when a fix is released. Please give us a reasonable chance to fix the problem before you share it publicly.

## Supported versions

The latest release is the one that gets security fixes. The plugin is in beta, so please update to the newest version.

## What counts

Examples: reading or changing records without permission, a way to get into the Hub without the right capability, injected SQL or script, exposed credentials such as an ActBlue secret, or a way to see donor data on a page that should be private.
