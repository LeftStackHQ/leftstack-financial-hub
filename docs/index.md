# Getting started

Financial Hub keeps your campaign's donations, expenses, and filing records in one place inside WordPress. It replaces the spreadsheet.

!!! note "This is a beta"
    The Hub is still being tested. Screens and wording may change, so check back here after you update.

## What you need

- A WordPress site. You'll need to be able to install plugins on it.
- WordPress 6.0 or newer, and PHP 8.0 or newer. Your host can tell you which PHP version you have.
- Ten minutes.

## The short version

1. [Install the plugin](install.md).
2. [Fill in the first-time setup](setup.md): your campaign name, starting balance, and filing periods.
3. [Connect ActBlue](actblue.md) if you use it, or [enter donations by hand](donations.md).
4. Enter [expenses](expenses.md) and [in-kind gifts](inkind.md), and [tie your records to the bank](bank.md).
5. [Check your records](before-you-file.md) and [export your state report](state-report.md) when a report is due.

## Good to know

- Financial Hub doesn't process donations. If you use ActBlue, donors still give through ActBlue, and the Hub pulls the records in.
- Everything stays in your own WordPress database. Nothing is sent anywhere unless you start an ActBlue sync.
- Right now the state report export works for Tennessee only.
